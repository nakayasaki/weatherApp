◆ 学び・メモ
JavaScriptから外部APIを利用する際、Node.jsをバックエンドとして挟むことで、APIアクセスキーなどの機密情報をブラウザ側に公開せずに管理できる。
APIアクセスキーなどの機密情報は、GitHubなどのリポジトリに直接アップロードしないよう注意する。
Node.jsはフレームワークではなく、JavaScriptをサーバーサイドで実行するための実行環境。
外部APIは仕様変更やサービス終了などの可能性があるため、バックエンド側でAPIとのやり取りを管理しておくと、変更の影響を抑えやすい。
外部APIを利用する際は、公式サイトで利用規約やAPIの仕様（利用回数、利用範囲など）を確認する必要がある。
API通信では、通信失敗や想定外のレスポンスなどを考慮して、エラー処理を実装することが重要。
世の中には、天気や画像などの身近なものから、少し変わったものまで、さまざまなAPIが存在することを知った。
backendとfrontendでファイルを分けたが、すべてfrontendに置いてしまったので整理したい。
